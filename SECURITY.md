# Security Policy

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us as outlined below.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security issue or vulnerability, please notify us immediately by emailing:
👉 **knfrt14@gmail.com**

To help us resolve the issue quickly, please include as much detail as possible in your report:
* A description of the vulnerability and its potential impact.
* Step-by-step instructions (or a proof-of-concept script) to reproduce the issue.
* Affected pages, URLs, or components.

## What to Expect

When you report a vulnerability privately, you can expect:
* **Acknowledgement:** We will acknowledge receipt of your vulnerability report within **24 to 48 hours**.
* **Assessment:** We will investigate and verify the reported issue.
* **Resolution:** If confirmed, we will work to patch the vulnerability as quickly as possible and notify you once it is fixed.

## Preferred Disclosure Policy

We ask that you give us reasonable time to investigate and fix any reported issues before publicly disclosing them. We appreciate your help in keeping this project and its visitors safe!
